# Lofty Hub app icon

The Gantt, tone on tone, all orange icon chosen in the Lofty Hub Icon study (`momentum/reference/lofty-hub-icon.html`), as the Hub ships it. Copied on 12 October 2026 from `app/public` in LoftySupport/loftyprojectapp (the Hub reads its own copy; change it there and here together).

| File | Size | Use |
| --- | --- | --- |
| `app-icon-1024.png` | 1024 | The master export, the Hub's web manifest and the App Store size |
| `icon-512.png`, `icon-192.png` | 512, 192 | Web manifest icons |
| `apple-touch-icon.png` | 180 | iOS home screen |
| `favicon-32.png`, `favicon-16.png`, `favicon.ico` | 32, 16, 16 to 32 | Browser tab |

The Hub's manifest sets `background_color` `#F47E63` and `theme_color` `#414042` (Foundation Black, which Momentum reserves for the black lockup; see the Hub's `docs/ui-system/BRAND_CHECK.md`).

Not yet made: the dark and tinted iOS variants. The icon still needs sign-off as a new mark (`momentum/HANDOFF.md`).
