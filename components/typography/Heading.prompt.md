One-line: page and section titles — `type` sets the size, `element` sets the tag, so document outline and visual weight stay independent.

```jsx
<Heading type="h1">Delivery dashboard</Heading>
<Heading type="h3" element="h2">This week</Heading>
<Heading type="h1" brand>Every job, every crew, one schedule.</Heading>
```

Sentence case always. `brand` swaps Montserrat for Fieldwork Geo Demi Bold — sign-in panels, decks and print only, never inside the app shell.
