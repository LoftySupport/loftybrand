# Button

Pill buttons that name the action. One primary (orange) action per area.

- **Primary:** `action` fill, `on-action` (Deep Eco) text. Never white text on orange.
- **Accent:** `eco-green` or `plum` fill with white text, for actions inside those surfaces.
- **Ghost:** transparent with a `line-control` border and `ink` text, for secondary choices and follow-up chips.
- Height 40px desktop, 44px on phones; `radius-pill`; label 13 to 14px bold.
- Press darkens orange to `orange-pressed`.
