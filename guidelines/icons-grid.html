Product set

Vibe icons

274 SVGs in assets/icons, rendered as a CSS mask over currentColor so every glyph inherits its context. Single-weight, mostly filled, rounded terminals — they read as solid rather than stroked at small sizes.

Construction set

Domain icons

Sixteen additions for the work the product actually describes. Each is a literal picture of the thing — houses for projects, a pin for a site, coins for cost — so it reads without English. Seven of them (Projects, JobSite, JobHouse, Design, FloorPlan, Maintenance, Reports) are Lofty-drawn line icons supplied as artwork; they render through the same mask so they take colour like the rest.
