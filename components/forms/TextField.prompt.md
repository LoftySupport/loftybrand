One-line: the default text input — label above, helper or error text below.

```jsx
<TextField label="Job name" placeholder="e.g. Northline resurfacing" value={v} onChange={set} />
<TextField label="Email" validation="error" message="Enter a valid email" />
```

Border goes Mid Gray → Foundation Black on hover → Crisp Orange on focus. Sizes small/medium/large map to 32/40/48px.
