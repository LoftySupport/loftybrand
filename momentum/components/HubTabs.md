# Tabs

Built in the Lofty Hub (`@lofty/ui`) on Vibe, themed by Momentum's tokens. Pictures: `guidelines/hub-tabs.html`. Source: `app/src/lofty-ui/components/Tabs.tsx` in LoftySupport/loftyprojectapp.

- Two shapes only (C50). **Tabs** are underlined: 44px high, label 14px at 600, an optional count badge (20px high, pill, 12px, on a neutral fill). **Pills** are 32px, pill-shaped, label 14px at 500, the selected pill white.
- Both take `TabItem`s and one component, `TabList`; there is no third shape. The dock's lifted-card tabs are retired.
- Measured live: tab 44px, pill 32px, count badge fill `#e1e1d9` in Sunrise (a Flint neutral; see the Hub's `BRAND_CHECK.md` F14).
