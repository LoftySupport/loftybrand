# DonutStat

One number only. Two or more slices belong in a bar chart, where the values can be read.

```jsx
<DonutStat value={82} caption="This week" />
```

The track is `--surface-recessed-color`, so it steps to Flint 700 on dark without any work. Keep the default `--data-1` arc unless the view is a green view, in which case pass `--highlight-color`.
